# Employment Management System

Frontend for an employment management platform covering Core HR, onboarding, time/leave, payroll, performance, and workforce operations.

## Structure

- `apps/web` — React + Vite + TypeScript + Tailwind admin frontend
- `docs/` — project documentation and slides

## Frontend

```bash
cd apps/web
npm install
npm run dev
```

App: `http://localhost:5173`
