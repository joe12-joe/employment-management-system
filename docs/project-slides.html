  • Auto sign-in after successful registration

06 — Technology

Tech stack

The frontend is built with a modern, maintainable stack aligned with the architecture plan.

Frontend

React 19, TypeScript, Vite 7, Tailwind CSS 4, React Router 7.

State & forms

TanStack Query, React Hook Form, Zod, Sonner toasts.

Planned backend

NestJS modular monolith, PostgreSQL, Prisma, Redis/BullMQ, S3-compatible storage.

Quality

Typechecked builds, responsive layouts, reusable UI components, API-ready structure.
